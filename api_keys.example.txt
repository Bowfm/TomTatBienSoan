# =====================================================================
# DANH SÁCH GEMINI API KEYS (DÀNH CHO CÔNG CỤ TÓM TẮT - BIÊN SOẠN)
# =====================================================================
# Cách cấu hình:
# 1. Đổi tên file này thành "api_keys.txt" (hoặc chạy setup.bat sẽ tự tạo).
# 2. Lấy API key miễn phí tại: https://aistudio.google.com/apikey
# 3. Dán các API key vào bên dưới, mỗi dòng 1 key (xóa dấu # ở đầu dòng).
#
# Hệ thống hỗ trợ từ 1 key cho đến 20, 30, 40+ keys:
# - Tự động xoay vòng thông minh (Round-Robin) giữa các key.
# - Tự động đổi key ngay lập tức nếu 1 key chạm hạn ngạch (Rate Limit).
# - Hỗ trợ chạy song song đa luồng cực nhanh (từ 4 đến 12 luồng cùng lúc).
#
# Ví dụ dán keys của bạn như sau:
# AIzaSy...key_thu_1...
# AIzaSy...key_thu_2...
# AIzaSy...key_thu_3...
